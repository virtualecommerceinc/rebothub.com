Roborock "Error 3" (wheels suspended) and "Error 4" (cliff sensor)

The robot stops and reports Error 3 or Error 4.

Documented: manufacturer or published sourceRisk: lowTools: Dry cloth

The Roborock Q7 Max manual: Error 3 "Wheels suspended. Move robot and restart." Error 4 "Cliff sensor error. Clean cliff sensors, move robot away from drops and restart." A Roborock forum report describes an S7 MaxV with a persistent Error 4 that a sensor swap did not cure, so a stubborn Error 4 can be a board-level fault.

Drafted with AI assistance from the sources named above. Not yet reviewed by Dan Herlehy; it will carry a review date when it has been.

🔧 Verdict: FixFix for the price of a cloth. A persistent Error 4 after cleaning is the one case where we recommend getting a used price for the robot before spending on parts, because the fault may not be the sensor.

Steps

  1. Error 3: set the robot on flat floor and restart. If it recurs on flat floor, flip it and check both wheels spring back when pressed.
  2. Error 4: flip the robot and wipe the cliff sensor windows around the front edge with a dry cloth.
  3. Move the robot at least a metre from any stair edge or dark rug and restart.
  4. If Error 4 persists on a clean light floor, note which sensor the app names if it does. A single failed sensor is a low-cost part but a fiddly swap. If a new sensor does not clear it, stop spending: compare the robot's used value against a repair-shop quote.
